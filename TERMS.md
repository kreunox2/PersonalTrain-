# Términos de uso

Última actualización: 1 de septiembre de 2026.

## 1. Qué es esto

Esta web ("Programa de banda") es una herramienta personal de seguimiento de
entrenamiento (rutina, marcado de sesiones completadas y estadísticas). Es un
proyecto personal, sin ánimo de lucro y de uso gratuito, publicado como código
abierto.

## 2. No es asesoramiento médico ni profesional

El contenido de esta web (ejercicios, cargas, duraciones, calendario de
entrenamiento) es orientativo y **no sustituye la valoración de un médico,
fisioterapeuta o entrenador cualificado**. Antes de empezar cualquier programa
de entrenamiento, especialmente si tienes una lesión previa, una condición
médica o llevas tiempo sin entrenar, consulta con un profesional de la salud.

El uso de esta herramienta y la ejecución de los ejercicios que describe es
responsabilidad exclusiva de la persona que entrena. El autor de esta web no
se hace responsable de lesiones, daños o perjuicios derivados del uso de la
información o del programa aquí incluidos.

## 3. Uso del sitio

- Puedes usar, copiar, modificar y adaptar el código de este sitio bajo los
  términos de la licencia MIT incluida en el archivo `LICENSE`.
- Puedes usar la rutina y su estructura como referencia personal. No se
  garantiza que sea adecuada para cualquier persona, nivel o condición física.
- El sitio se ofrece "tal cual", sin garantías de disponibilidad, ausencia de
  errores o continuidad del servicio.

## 4. Cuentas y datos

Esta web no tiene sistema de registro ni cuentas de usuario. No hay backend:
todo el progreso (marcas de ejercicios, rachas, motivos de no entrenar) se
guarda **únicamente en el navegador** de quien la usa, mediante
`localStorage`. Consulta la `PRIVACY.md` para más detalle.

## 5. Modificaciones de estos términos

Al ser un proyecto personal publicado en GitHub, estos términos pueden
actualizarse libremente editando este archivo. La versión vigente es siempre
la publicada en el repositorio.

## 6. Contacto

Este proyecto no ofrece soporte formal. Si detectas un error, puedes abrir una
"issue" en el repositorio de GitHub donde está publicado este código.
